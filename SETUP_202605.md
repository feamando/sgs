*Windows + RTX 4090. Other platforms are not validated.*

Active tracks only. Completed work (Planck 1.0-1.3.0, Raum 1.0-1.2,
Raum 0.0-0.1) is archived in git history. See `roadmap.md` for the
full project timeline.

Satz 0.1 needs the blob index (§2). Planck 1.4 can run in parallel
(it uses the same Planck 1.3 checkpoint but doesn't need the blob
index). Raum 1.3 starts after both ship.

## 2. Planck 1.3.1a — Wikipedia blob index

**Status:** needs run. Prereq for Satz 0.1.

Builds 200k knowledge blobs from Planck 1.3's Wikipedia embeddings.
Uses Faiss GPU clustering (falls back to sklearn if Faiss unavailable).

### 2.1 Install Faiss (recommended)

```powershell
pip install faiss-gpu
```

If `faiss-gpu` fails (Windows wheels are spotty), the script falls back
to sklearn MiniBatchKMeans (slower, ~5h vs ~30min).

### 2.2 Build blob index

```powershell
python scripts\build_blobs.py `
  --data-dir data\wikipedia `
  --checkpoint checkpoints\planck13\best.pt `
  --n-blobs 200000 `
  --output data\blobs\wikipedia
```

### 2.3 Verify

```powershell
python -c "import torch; d=torch.load('data\blobs\wikipedia\blobs.pt', map_location='cpu'); print(f'Blobs: {d[\"mu\"].shape[0]}, d_s={d[\"mu\"].shape[1]}, d_f={d[\"features\"].shape[1]}')"
```

Expected: `Blobs: 200000, d_s=128, d_f=1000`

## Troubleshooting

### CUDA out of memory

Reduce `--batch-size`. The 4090 has 24 GiB; Planck 1.3 at batch 32
with context 512 uses ~8 GiB. Blob retrieval adds ~2 GiB for k=8 at
200k blobs.

### Faiss won't install

Use sklearn fallback (automatic). Or try: `pip install faiss-cpu`
(slower than GPU but faster than sklearn at k=200k).

### PowerShell line continuations

Use backtick (`` ` ``) at end of line, not `^` (that's cmd.exe).
