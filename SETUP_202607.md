## 2. P6 Correlation hypothesis validation

**Status:** ready to run. Script at `scripts/validate_p6_correlation.py`.

This is the make-or-break experiment. If R^2 > 0.7, we proceed with
Physical Gaussians. If R^2 < 0.5, the architecture needs rethinking.

### 2.1 Run with GloVe (real validation)

```powershell
python scripts\validate_p6_correlation.py `
  --glove-path data\glove\glove.6B.300d.txt `
  --output results\p6_correlation_validation.json `
  --epochs 500 `
  --folds 5
```

### 2.2 Run without GloVe (pipeline test only)

```powershell
python scripts\validate_p6_correlation.py `
  --output results\p6_correlation_test.json
```

### 2.3 Gate

| Metric | Threshold | Meaning |
|--------|-----------|---------|
| Overall R^2 | > 0.70 | Strong: proceed with full architecture |
| Overall R^2 | 0.50 - 0.70 | Moderate: proceed with caveats |
| Overall R^2 | < 0.50 | Weak: rethink (may need non-semantic features) |
| Per-property R^2 (hardness) | > 0.80 | Hardness is most important for physics |
| Per-property R^2 (elasticity) | > 0.60 | Elasticity matters for deformation |

### 2.4 If hypothesis fails

Fallback options:
- Add geometric features (scale, opacity) to the input (the MLP already supports this)
- Use Planck contextual embeddings instead of GloVe (richer context)
- Use a larger material table with more diverse examples
- Accept partial prediction + manual override for edge cases

## 7. Klang integration (impact sounds)

**Status:** blocked on §6.

### 7.1 Sound synthesis from e_p

When an object collides with a material region:
- Read e_p of the impacted Gaussians
- Map e_p hardness + density to frequency (harder + denser = higher pitch)
- Map e_p elasticity to decay time (more elastic = longer ring)
- Map geometry (Sigma) to resonance (larger = lower fundamental)

### 7.2 Demo

```powershell
python scripts\impact_sound.py `
  --scene output\castle_with_physics.json `
  --impact-point "1.0, 2.0, 0.5" `
  --velocity 5.0 `
  --output output\impact_stone.wav
```

### 7.3 Gate

- Stone impact: sharp, high-frequency, fast decay
- Wood impact: medium frequency, moderate decay, thud
- Metal impact: high frequency, long ring
