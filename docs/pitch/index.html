The Problem

Text-to-3D is stuck at monolithic generation

Current systems (DreamFusion, DALL-E 3D) produce opaque blobs. No parts. No labels. No editing without full re-generation.

  • Cannot change roof color without regenerating entire scene
  • Cannot move one object without affecting others
  • Cannot query "what is left of the gate?"
  • 1-4 GPU-hours per scene, $50-200 per generation

Our Solution

Recursive Semantic-to-Geometric Decomposition

A language model decomposes prompts into composition trees. Each node is a named sub-concept with spatial relations. Terminal nodes are individual Gaussian splats.

"a castle on a hill" | v [Decomposer LM] --> Composition Tree: | scene v +-- castle (pos=[0,0.8,0]) [Recursive | +-- tower_1 (cylinder + cone) Renderer] | +-- tower_2 (cylinder + cone) | | +-- keep (box + cone) v | +-- gate (arch) [3D Gaussians] +-- hill (dome, green) | v Editable Scene Graph + 3D Render
3 / 8

Key Innovation

Same math from language to geometry

Proven Foundation

Alpha-compositing (our rendering equation) is a strict superset of softmax attention. Formally verified in Lean 4. Submitted to JMLR.

Editable by Design

The composition tree IS the representation. Change a node name, position, or color; re-render instantly. No re-generation needed.

Compositional Memory

Knowledge stored as "blobs" (Gaussian primitives). 40% retrieval recall at 90-turn distance. Flat cost per turn regardless of history length.

Applications

Game Asset Generation

"Medieval village with a blacksmith" -> editable scene with labeled buildings, props, and terrain. Drag to reposition. Swap components from library.

Architectural Visualization

Building descriptions -> 3D walkthroughs with editable floor plans. Change materials, add rooms, modify layout through language.

Film Pre-visualization

Script descriptions -> scene layouts -> 3D previews. Directors iterate on composition before any modeling work begins.

Education / Scientific

"Show me a cell with the mitochondria highlighted" -> labeled 3D model with queryable parts. Interactive, decomposable, accessible.
